📁 Excel File Splitting System

🔧 How It Works:

  • 500,000 records per file: Optimal size for Excel performance
  • Automatic splitting: Large datasets split into multiple files
  • Sequential downloads: Files download one by one with small delays
  • Consistent naming: Files named as "part1of3", "part2of3", etc.
  • Same structure: All files have identical column structure

📋 File Naming Examples:

  • account-numbers-2026-03-16T10-30-45.xlsx (Single file)
  • account-numbers-2026-03-16T10-30-45-part1of3.xlsx (Multi-file part 1)
  • account-numbers-2026-03-16T10-30-45-part2of3.xlsx (Multi-file part 2)
  • account-numbers-2026-03-16T10-30-45-part3of3.xlsx (Multi-file part 3)

✅ Benefits of File Splitting:

  • No Memory Errors: Avoids "Too many properties to enumerate"
  • Better Performance: Smaller files load faster in Excel
  • Manageable Size: Each file is under Excel's optimal limit
  • No CSV Fallback: Always generates Excel files as requested
  • Progress Tracking: Shows progress for each file
