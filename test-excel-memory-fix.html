🔧 Memory Fix Details

Problem: "Too many properties to enumerate"

This error occurs when:

  • Dataset is too large for Excel's memory handling
  • XLSX library runs out of memory creating the workbook
  • Too many object properties are created during export

Solution Applied:

  • ✅ Row Limit Check: Automatically use CSV for datasets > 1M rows
  • ✅ Memory Optimization: Use array of arrays instead of objects
  • ✅ Minimal Options: Disable cell styling and unnecessary features
  • ✅ Duplicate Removal: Remove duplicate numbers to reduce size
  • ✅ Compression: Enable compression in writeFile options
  • ✅ Smart Fallback: Automatic CSV fallback on Excel failure
  • ✅ Better Error Messages: Clear guidance when Excel fails
